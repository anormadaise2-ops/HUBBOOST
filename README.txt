HUBBOOST - PROJET COMPLET

Fichiers:
- index.html : page de téléchargement
- download/HUBBOOST.bat : BAT complet avec 500 options
- download/HUBBOOST-500-CATALOGUE.txt : catalogue des 500 options
- HUBBOOST.bat : copie directe
- HUBBOOST-500-CATALOGUE.txt : catalogue

UTILISATION:
1. Ouvrir index.html dans un navigateur.
2. Cliquer sur "Télécharger HUBBOOST.bat".
3. Clic droit sur le BAT -> Exécuter en tant qu'administrateur.
4. Le menu affiche 001 à 500.
5. Entrer un numéro puis Entrée.

A = exécuter les 500
I = informations CPU/GPU/RAM
R = restauration principale
0 = quitter

IMPORTANT:
Les options de nettoyage, diagnostic et réparation ne sont pas toutes des boosts FPS.
Le script ne force aucun overclock matériel ni changement de tension.
